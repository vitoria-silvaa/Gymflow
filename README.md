# Gymflow

Sistema web para gerenciamento de academias, desenvolvido como projeto de conclusão do curso Técnico em Desenvolvimento de Sistemas da ETEC.

## Funcionalidades

- Cadastro e gerenciamento de alunos
- Cadastro de filiais
- Planos e matrículas
- Controle de pagamentos e contas
- Login e controle de acesso
- Dashboard com informações do sistema

## Tecnologias utilizadas

- PHP
- MySQL
- HTML5 e CSS3
- JavaScript
- Bootstrap
- Arquitetura MVC
- Git e GitHub

## Como executar o projeto

1. Clone este repositório.
2. Copie a pasta para o diretório `htdocs` do XAMPP.
3. Inicie o Apache e o MySQL pelo XAMPP.
4. Importe o arquivo do banco de dados localizado na pasta `database`.
5. Acesse o projeto pelo navegador:

```text
http://localhost/Gymflow
